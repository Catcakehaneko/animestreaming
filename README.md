# HiAnime + MegaPlay Streaming Single-Page Application

A lightweight, purely static front-end web application that connects the HiAnime/Anikoto catalog to the **MegaPlay.buzz** stream embed network.

## How to Deploy on GitHub Pages

1. **Create a GitHub Repository**:
   - Go to [GitHub.com](https://github.com) and click **New Repository**.
   - Name it `hianime-web` (or any name you choose).
   - Keep it **Public** and click **Create repository**.

2. **Upload Files**:
   - Upload `index.html`, `app.js`, and `README.md` directly into the root folder of your newly created repository.

3. **Enable GitHub Pages**:
   - Inside your repository, go to **Settings** -> **Pages**.
   - Under **Build and deployment**:
     - **Source**: Select `Deploy from a branch`.
     - **Branch**: Select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.

4. **Access Your Application**:
   - After 1–2 minutes, GitHub Pages will output a live URL:
     `https://<your-github-username>.github.io/<repository-name>/`
